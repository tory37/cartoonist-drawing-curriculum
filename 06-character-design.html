A real, repeatable design drill — not a one-off

The Etherington Brothers’ 3-Shape Characters method is built to be run over and over, not done once: split a body into three sections, then randomly pick each section’s height (short/medium/tall) and width (narrow/medium/wide). Every combination produces a different, usable silhouette. Run it weekly with a fresh random combination — it’s how the Etheringtons themselves teach building a personal library of shapes fast.

exercises Run the 3-Shape drill weekly, then draw an expression sheet (and eventually a full turnaround model sheet) for whichever result you liked best that week — exactly where your module 02–03 construction work pays off.
